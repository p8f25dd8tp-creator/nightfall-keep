# NIGHTFALL KEEP

Ein browserbasierter Mobile-Prototype: tagsüber die Festung ausbauen, nachts drei Angriffsrouten verteidigen.

## Steuerung

- Linker Daumenstick oder WASD/Pfeiltasten: Held bewegen
- Held und Verteidigungsgebäude greifen automatisch an
- Tagsüber ein Gebäude wählen und auf einen freien Platz in Festungsnähe tippen
- Ein bestehendes Gebäude antippen, um es für Gold aufzuwerten
- Häuser und Mühlen erzeugen tagsüber Gold; besiegte Gegner lassen Gold fallen
- Heldenverbesserungen aus Level-ups bleiben nach Niederlagen gespeichert
- ×1 / ×2 / ×3 ändert die Spielgeschwindigkeit

## Starten

Das Spiel liegt vollständig in `index.html` und benötigt keine Installation oder externe Bibliotheken. Für einen direkt antippbaren Link muss das Repo noch über einen Webhost wie GitHub Pages veröffentlicht werden; die Datei allein ist der Spielcode.
